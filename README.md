# 라꿍이의 모험 (등척성 2.5D 액션 어드벤처)

작은 마피아 보스 라꿍이가 도시의 구역을 되찾는 웹게임 (Phaser 3, PC · 모바일 브라우저).
건물·소품·바닥 텍스처·NPC·적은 모두 **AutoSprite로 생성**했고, 참고 이미지(따뜻한 석양 조명, 주황 벽돌 골목, 박스형 3D 장난감 캐릭터)의 스타일로 통일했습니다.

## 게임 2종
- **라꿍이의 모험** (`game/index.html`): 등척성 2.5D 액션 어드벤처 (마피아 구역 되찾기). **챕터 1~4**: 캣 패밀리(돈 캣) → 스카이 크루(구구 대장) → 언더그라운드(치즈 왕), 자동 저장·이어하기
- **라꿍이의 집으로 가는 길** (`game/home/index.html`): 횡스크롤 플랫포머. 골목·공원·강변·야경 골목·비 내리는 공원·달빛 강변 **6스테이지**, **코끼리·독수리 타기**, 움직이는 발판·스프링·함정, 사과 던지기·밟기, 글자(라·꿍·이) 수집, 보스 3종(돈 캣·구구 대장·치즈 왕)

## 실행 방법
### PC
`실행하기.bat` 더블클릭 → `http://localhost:5177` (Node.js 필요, 없으면 Python 3).
직접 실행: `node serve.js game 5177`

### 휴대폰 (같은 Wi-Fi)
1. PC에서 `실행하기.bat` 실행 (창에 `폰 접속 주소: http://192.168.x.x:5177` 이 표시됩니다)
2. 휴대폰 브라우저에서 그 주소를 열기 → **가로 모드**로 돌리면 터치 조작이 나타납니다.
- 방화벽 허용 창이 뜨면 "허용"을 눌러야 접속됩니다.
- 인터넷에 공개 배포(누구나 접속)는 하지 않았습니다. 원하시면 말씀해 주세요.

## 조작 (라꿍이의 집으로 가는 길)
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | ← → / A D | 왼쪽 조이스틱 (끝까지 밀면 달리기) |
| 점프 | Space / ↑ | ⤴ 버튼 |
| 사과 던지기 / 코끼리 돌진 | J | 사과 버튼 |
| 새장 열기·타기·내리기 | E | E 버튼 |
| 독수리 비행 높이 | ↑ ↓ | 조이스틱 위·아래 |

## 조작 (라꿍이의 모험)
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 조이스틱 (끝까지 밀면 달리기) |
| 달리기 | Shift | 조이스틱 끝까지 / 🏃 버튼 |
| 점프 | Space | ⤴ 버튼 |
| 대화·상호작용 | E | E 버튼 (근처에 대상이 있으면 깜빡임) |
| 물기 (콤보 3타) | J (누르고 있으면 연속) | 🦷 버튼 |
| 돌진 | K (쿨 4초) | 💨 버튼 |
| 왕짖기 (기절 1.5초) | L (쿨 8초) | 📢 버튼 |
| 조직원 호출 | R (3단계 개방, 현재 잠금) | 🔒 버튼 |
| 일시정지 | Esc / P | 오른쪽 위 ⏸ |
| 스프라이트 모드 | V (8방향 ↔ 정면) | 일시정지 메뉴 |

## 사용성(UI/UX) 다듬기
- 화면 전환 페이드, 챕터·스테이지·보스 등장 배너, 로딩 진행바, 버튼 눌림/반짝임 효과
- 배경음악(타이틀·마을·보스·낮·밤·비) + **소리/진동 설정**(타이틀·일시정지 화면, PC는 M 키로 음소거). 설정은 이 브라우저에 저장됩니다.
- 모바일: **플로팅 조이스틱**(왼쪽 화면 아무 곳이나 누르면 그 자리에 생김), 버튼 터치 진동
- 피격 시 붉은 화면 번쩍임·진동, 체력 30% 이하 경고, 체력바 잔상
- 라꿍이의 모험: 목표 방향 화살표(+거리), NPC 대화창 초상화, 결과 화면 숫자 카운트업
- 집으로 가는 길: 점프 늘어남/착지 찌그러짐, 달리기 먼지, 별 자석, 진행 방향 카메라, 하트·카운터 애니메이션, 클리어 **별점(최대 ★3)** 과 스테이지별 최고 기록

## 현재 구현
- 등척성 월드 36×36: 텍스처 바닥(석판·아스팔트·보도), 입체 건물 12종, 소품, 달리는 차량(4방향), 그림자, 앞뒤 가림, 충돌
- 라꿍이 8방향 이동·달리기·점프, 물기/돌진/왕짖기, 체력·경험치·레벨 1~10
- 적(캣 조직원) AI: 탐색→경계→추격→공격 준비→공격→후퇴→복귀, 협동 경계
- 구역 6개(지배 조직·HUD·미니맵 색), 챕터 1(보고→훈련→캣 3마리→냥냥 사장님), 사이드 의뢰(치킨)
- 모바일: 터치 조이스틱/버튼, 가로 모드 안내, 반응형 HUD, 전체화면
